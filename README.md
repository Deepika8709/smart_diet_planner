# smart_diet_planner
smart diet planner is a python based program about how a person can choose his fitness goal according to weight loss or Muscle gain program
This project was created to practice:

data cleaning

filtering

logical conditions

and real-world recommendation logic.

What this program does :

Reads food nutrition data from a CSV file

Cleans and converts values into numeric form

Asks the user to choose a goal:

Weight Loss

Muscle Gain

Filters foods based on protein, calories, and fiber

Displays recommended foods for that goal

Technologies Used:

Python
Pandas
csv file handling
